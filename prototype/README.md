# Northstar Mock Data 原型

## 開啟

原型是無建置步驟的靜態頁面。可直接開啟 `index.html`，或在此資料夾執行：

```powershell
python -m http.server 4173
```

再瀏覽 `http://localhost:4173`。不需安裝套件或提供 API 憑證；原型不會發出平台 API 請求。

## 操作

1. 在「成效總覽」切換正常同步、更新延遲、部分缺漏、口徑差異、同步失敗情境，觀察資料狀態與彙總數值。
2. 進入「每週建議」，選擇採納、部分採納或不採納，可記錄日期及自訂的手動調整金額。
3. 在「決策紀錄」檢視狀態、日期和調整金額。兩個報告週期可分別記錄。紀錄儲存在瀏覽器 localStorage；「清除示範紀錄」會刪除本機原型紀錄。
4. 「指標定義」和「欄位映射」可檢視暫定公式及示範來源對照。

## 驗收情境

- 正常同步：三個平台列出合成數據；CVR 與支出可計算；跨平台 CAC 顯示不可用，理由為跨平台去重未核准。
- 更新延遲：顯示受影響平台、延遲狀態及最近成功更新時間；示意建議暫停。
- 部分缺漏：缺漏值顯示為空值而非零；跨平台 CVR 不顯示完整彙總。
- 口徑差異：品牌官網標示口徑待確認；跨平台 CVR 不顯示完整彙總。
- 同步失敗：平台指標不以舊值填補；顯示同步失敗及最近成功更新時間。
- 決策追蹤：採納、部分採納、不採納皆可記錄；輸入的金額只作為手動調整紀錄，沒有平台寫入功能。
- 歷史檢視：決策日期、狀態與手動調整金額可回看；尚無紀錄時顯示空狀態。

上述為 Mock Data 原型驗收，不等於真實平台整合、資料字典核准、使用者研究或正式研究放行。
