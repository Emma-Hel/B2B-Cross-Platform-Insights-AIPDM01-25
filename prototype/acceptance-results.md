# Mock Data 原型驗收結果

日期：2026-11-10　｜　環境：Chrome，`http://localhost:4173/`　｜　資料：合成資料

| 驗收項目 | 結果 | 證據/限制 |
| --- | --- | --- |
| AC-01：檢視三平台績效 | 通過（原型） | 正常情境顯示 Amazon Ads、Alibaba.com、品牌官網的合成績效列。不是平台 API 匯入驗收。 |
| AC-02：一致口徑 CVR/CAC | 通過（原型邊界） | 分平台 CVR/CAC 依暫定公式顯示；跨平台 CVR 在完整/可比較時為 4.08%，資料缺漏或口徑待確認時顯示不可用；跨平台 CAC 明確顯示不可用，原因為去重未核准。 |
| AC-03：缺漏/異常提示 | 通過（原型） | 更新延遲、部分缺漏、口徑差異及同步失敗四種情境均顯示來源狀態；不以缺漏值補零或把部分資料當成完整彙總。 |
| AC-04：期間與資料狀態 | 通過（原型） | 可切換兩個週期；週期資料、平台更新時間、同步/品質狀態均可見。 |
| 每週示意建議 | 通過（示意功能） | 正常情境開放採納/部分採納/不採納；其餘資料品質情境停用採納操作並保留不採納。內容明確標示為示意，非核准規則。 |
| 手動調整與歷史 | 通過（原型） | 驗證三種決策狀態、日期、可選金額及跨週歷史顯示；紀錄只寫入本機 localStorage，不會變更平台預算。 |
| 瀏覽器診斷 | 通過 | Console 無錯誤或警告；網路請求只有 localhost 靜態頁面、CSS、JS 和瀏覽器內建 data URI，沒有外部平台/API 請求。 |

## 未通過/未驗證項目

- 原始單元 5 Spec 未隨工作區提案提供；目前 AC-01～AC-04 僅依提案內明確標註為摘要的文字與兩份 capability spec 驗收，原始條文仍待取得後核對。
- 真實平台權限、API 欄位、更新頻率、歷史範圍、商用費率、客戶資料與跨平台去重均未驗證。
- SAP、正式資料字典、歸因/差異查核/有效樣本及研究放行規則尚未由研究負責人核准；正式每週建議規則與流程尚未由目標使用者核准。
- 5 家、4 週探索與正式研究不在本原型驗收範圍內。
